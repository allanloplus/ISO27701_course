# ISO/IEC 27701:2025 隱私資訊管理系統（PIMS）完整課程

講師：**Allan**（ISMS／PIMS 輔導顧問、驗證機構稽核員）｜助教：**阿拉蕾**

依據 ISO/IEC 27701:2025（2025-10 發行）製作的完整課程，涵蓋三大面向：

1. **標準詳細解說**：第 4–10 章要求事項、附錄 A 共 78 項控制措施（A.1 控制者 31、A.2 處理者 18、A.3 共通安全 29）與附錄 B 實作指引
2. **對應的 PIMS 管理作法**：要建立的程序、表單、紀錄與範本欄位
3. **常見稽核實務**：稽核員提問、應備證據、不符合事項寫法範例

## 使用方式

- **直接開啟**：用瀏覽器開啟 `site/index.html` 即可（不需伺服器，離線可用）。
- **放上網路（GitHub Pages）**：在 GitHub repo → Settings → Pages，選擇此分支、資料夾 `/ (root)`，網址即為 `https://<帳號>.github.io/<repo>/`。
- 也可把 `site/` 整個資料夾上傳到任何網站主機或公司內部 LMS。

## 互動影音設計（避免載入過久）

- 每章、每個場景、每一句台詞都拆成獨立的小 MP3（約 20–80 KB），按下播放只需下載第一句即可開始；播放時自動預載後面 2 句。
- 章節資料按需載入，不會一次下載整門課。
- 可從場景清單直接跳播、調整語速（0.9x–1.5x）、開關字幕、看逐字稿。
- 若語音檔無法載入，會自動改用瀏覽器內建語音（zh-TW）或依字幕時間繼續播放。

## 課後測驗

- 10 題單選，每題 10 分，**80 分及格**；每次測驗選項順序會隨機打亂。
- **及格**：填寫公司名稱、單位、姓名、職稱、e-mail（全部必填）→ 產生結業證書，可下載證書 PNG、測驗題目與解答 PNG，或列印／另存 PDF。
- **未及格**：顯示分數與建議複習的章節連結，可重新閱讀或重新測驗（未及格不顯示解答）。
- 資料僅在學員瀏覽器內產生證書，不會上傳。若需集中收集學員名單，可再串接 Google 表單或公司 LMS。
- 題目在 `site/assets/quiz-data.js`，可自行修改。

## 內容維護（給講師）

章節內容的唯一來源是 `content/chapters/chNN.json`（格式見 `content/SPEC.md`）。修改後執行：

```bash
pip install edge-tts                  # 第一次需要
python3 tools/build.py --tts          # 重建網站資料，並只為「有變更的台詞」重新產生語音
cd tools && npm install && cd ..
node tools/make_pptx.js               # 重建 PPTX 簡報
```

- 語音：Allan 使用 `zh-TW-YunJheNeural`（台灣男聲），阿拉蕾使用 `zh-TW-HsiaoYuNeural`（年輕女聲，略提高音調）。語音由 Microsoft Edge 線上神經語音服務產生；若要對外商業販售課程，建議改用 Azure AI Speech 正式授權重新產生（`tools/build.py` 中的 `VOICES` 可調整）。
- 人物圖：由講師提供的插圖裁切而成（`site/assets/img/`、`tools/img/`）。
